# Paxos Made Simple

By Leslie Lamport

[Link to Paper](https://lamport.azurewebsites.net/pubs/paxos-simple.pdf)

This paper is not part of the MIT 6.824 reading list but I have seen Paxos cited by multiple other papers and wanted a basic understanding of it.

This paper describes the basic Paxos algorithm and how it can be used to implement a replicated state machine.

[This blog post](https://angus.nyc/2012/paxos-by-example/) does a good job providing an example of how the basic algorithm typically works.

[The Wikipedia entry for Paxos](https://en.wikipedia.org/wiki/Paxos_%28computer_science%29) lists several variants of Paxos including multi-paxos and fast paxos which give better performance under certain conditions.
